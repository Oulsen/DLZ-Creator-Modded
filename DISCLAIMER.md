**Unofficial.** DLZ Creator Modded is a community project. It is not affiliated with or endorsed by Mackie or LOUD Audio. All trademarks belong to their owners.

**Alpha (early and experimental), use at your own risk.** No warranty of any kind: you decide to
install it, and you carry the consequences.

**Your mixer's warranty.** Mackie does not support this mod. Installing or using it **could void
your mixer's warranty**. For problems with the mod, ask us (GitHub issues or Discord), not Mackie
support. Before you contact Mackie about anything else, take the card out and check that the problem
also happens with the mixer's normal software.

**Supported devices.** The Mackie DLZ Creator XS and DLZ Creator with firmware v1.2 build 1731. The XS is tested; the full-size DLZ Creator has the same main board and firmware as the XS and an owner has installed and run the mod on one, but it is not on our test bench. Other firmware builds are not supported; the mod refuses to install on them. On those the installer can save a backup of the internal storage for analysis instead (only read, not yet tried on such a mixer).

**What it touches.** The mod runs from a microSD card. By design, the mixer's internal storage is only read, never written: take the card out and the mixer is stock again. This is how it is built, not a guarantee.

**Never:**
- install a Mackie firmware update with the mod card inserted (the mod refuses this anyway)
- let Windows format the card's Linux partition when it offers to

**No Mackie software is distributed.** Everything is built from a copy of your own mixer.

**Built with AI assistance.** The maintainer leads the reverse engineering, design and testing, and uses Claude Code as a development tool for code and notes. Every change is reviewed and tested on a DLZ Creator XS with build 1731 before release; the full-size DLZ Creator gets the same software; an owner runs it on one, but it is not on our test bench.
