# Security

The mod runs on a mixer that people use on stage and in the studio, with parts that run as root.
If you find a way into the mixer, or around the mod's safety locks (the internal storage that must
stay untouched, the firmware and update guards, the update signatures), please report it privately:

- **[Report a vulnerability](https://github.com/Oulsen/DLZ-Creator-Modded/security/advisories/new)**
  (GitHub's private reporting), not in a public issue or on Discord.
- Say which mod version and mixer, what someone can do with it, and how to reproduce it.

You get an answer in the report. A fix ships in a release; the report becomes public after that,
with credit if you want it.

Only the latest release gets fixes. Known limits that are not secret are listed in the README ("Is it
safe?") and in the issues, such as stock behaviour on the network (#45).
